# 轻课表 · 今日课程

一个零依赖、单文件的本地课表网页（类似「Wake Up 课程表」）。打开就是**当天的课程**，支持**导入教务系统 / Excel 的整张课表**（课程时间、节次、时长、周次自动换算），导入后可自由调整、添加、删除。

- 主程序：`index.html`（单文件、零依赖，双击即可用，无需联网、无需安装）
- 本地服务器：`server.js`（仅用 Node 内置模块，零依赖）
- 一键启动：双击 `启动.bat`；手机访问双击 `启动-手机访问.bat`
- 无构建步骤、无 npm 依赖、无框架

## 打开方式

**方式一（推荐）**：双击 `启动.bat` → 浏览器自动打开 <http://127.0.0.1:5188/>

**方式二**：命令行

```bash
node server.js          # 默认 5188 端口
node server.js 8080     # 换端口
node server.js 5188 lan # 允许手机在同一 WiFi 下访问（会打印局域网地址）
```

**方式三**：直接双击 `index.html`（file:// 方式，功能完全一致，数据同样存在本机浏览器）

## 界面

| 标签 | 内容 |
| --- | --- |
| 📅 今日 | 默认打开页。今天第几周、当前正在上的课（含进度条、剩余分钟）、下一节课倒计时、今日课程时间轴、未来 7 天安排 |
| 🗓 课表 | **单日 / 整周** 两种模式。单日：一屏看完一天，按节次列出时间轴、连堂课画延续色条、点空行即添加、左右滑动换天；整周：网格视图，可翻周、节次栏显示起止时间、同一时段冲突的课自动并排、红色横线是当前时间 |
| 🔍 课程 | 检索课程 / 教师 / 教室 / 周次；统计课程数、每周节数、每周课时；逐条编辑、复制到别的时间、删除 |
| ⚙️ 设置 | 开学日期、学期总周数、显示周末、主题；作息时间表逐节自定义；导入 / 导出 / 载入示例 / 清空 |

> 想把桌面上的 Excel 课表导进来：点「课程」→「📥 导入 / 检索课表」→ **把文件直接拖进弹层**（或点「选择文件」）。

## 第几周 / 日期对不上怎么办

App 里所有「第 N 周」和每个星期几下面的日期，都是按**开学第一周的周一**推算的。默认它把「你第一次打开的那一周」当成第 1 周，所以刚装好时周次和日期是错位的 —— 设一次就永久对齐了。

三个入口，任选其一：

- **今日页**：日期那一行点「调整学期时间」
- **课表页**：点中间的「第 N 周」
- **设置页**：学期设置 →「开学第一周的周一」，或点「按今天校准」

弹层里两项**填任意一个，另一个自动跟着变**：

- **今天是第几周** —— 知道这周是第 5 周就直接填 5，开学日期会自动算出来（最省事，推荐）
- **开学第一周的周一** —— 知道确切开学日期的就填这个

下面会实时显示「开学第一周：2026年9月2日（周一）～ 9月8日（周日）」「本周 10/19 ~ 10/25 就是第 5 周」，确认无误再保存；填的日期不是周一时会提示「已按它所在那一周的周一计算」。

保存后，周课表表头每个星期几下面的日期、手机端单日视图的星期条、今日页的「第 N 周」会全部同步更新。

> 没设置过的时候，今日页顶部会有一条提示（点「知道了」可永久关掉）。

## 手机端

- **课表页自动切成「单日时间轴」**：手机上不再需要横向拖动整张网格，一屏看完当天所有节次；有课的行显示卡片（课程名 / 起止时间 / 节数 / 时长 / 教室 / 教师 / 周次），没课的行点一下就能添加，连堂课下面的行画成同色延续条，节次编号不会断号。
- **左右滑动切换星期**，划到周日/周一会自动翻到上/下一周；也可以点顶部星期条直接跳。
- 想看在整周网格（可以双指缩放页面），点右上角 `单日 / 整周` 随时切换，宽屏默认整周、窄屏默认单日。
- 触控与显示细节：底部导航栏与弹层适配 `env(safe-area-inset-*)` 刘海/小白条，弹层在手机上是从底部升起的抽屉、按钮在底部并排铺满，输入框在 iOS 上不会因为字号过小而被自动放大，禁用了双击缩放与点击高亮，整周网格的星期表头与节次栏滚动时固定不动。
- **添加到主屏幕**：手机浏览器菜单里选「添加到主屏幕 / 安装应用」，会以全屏无地址栏的方式打开（已带 `manifest.webmanifest` 与图标 `icon-192/512.png`）。

## 导入课程（核心）

点「导入 / 检索课表」后，**直接把 Excel 文件拖进弹层**，或点「选择文件」选它，程序会自动读完并列出结果；也可以把内容粘贴进文本框后点「🔎 检索 / 解析」。**识别结果会先列成表格**，每一格都能改，确认后点「全部导入」。重复课程可选「跳过 / 覆盖 / 全部导入」。

支持的文件格式：

| 格式 | 说明 |
| --- | --- |
| `.xls` | Excel 97-2003（教务系统导出最常见）。内置 OLE2 + BIFF8 解析，支持合并单元格、共享字符串表、RK 数值 |
| `.xlsx` / `.xlsm` | 现代 Excel。内置 zip + deflate 解析（用浏览器原生 `DecompressionStream`，无需联网、无需第三方库） |
| `.csv` / `.tsv` / `.txt` | 自动识别 UTF-8 / GBK 编码（Excel 导出的中文 CSV 多为 GBK） |
| `.json` | 唤醒课程表 / 小爱课程表导出，或自定义数组 |

支持的内容结构：

1. **教务系统个人课表（矩阵式，一格多课）** —— 自动识别这种单元格：

   ```
   课程名 [（分组02）] 教师 周次(周)[节次] 地点
   计算机辅助设计 林宁 1-5,7-8(周)[05-06-07-08节] (儋州)DSP技术应用实验室（1405）
   ```

   一个格子里塞了多门课也会全部拆出来；纵向合并单元格导致的重复会自动去重；`(分组02)` 会保留在课程名里。

2. **列表式表格**（教务系统 / Excel 复制粘贴，首行有表头即可，前面有标题行、后面有备注行也不影响）：

   ```
   课程名称	教师	星期	节次	周次	地点
   大学语文	郑华	周一	3-4	1-16	教二301
   高级英语	Linda	周三	1-2	1-16单	外语楼101
   ```

3. **矩阵式课表**（行=节次、列=星期）—— 逐节书写的相邻同名课程会自动合并成连堂。

4. **一行式自由文本**（手写也能识别）：

   ```
   高等数学 张伟 周一 1-2节 1-16周 教一101
   周一 08:00-09:40 大学物理 陈静 理科楼401
   周三 12:30-13:30 午间沙龙 活动中心
   ```

### 自动识别学校真实作息时间

如果课表的行标签里带着学校的节次时间（例如 `1、2节 (01,02) 07:40-09:20`），导入时会**自动反推出整套作息时间表**并在预览顶部给出勾选框，默认勾选。确认导入后作息表会被替换，所有课程时间按学校真实时间换算 —— 例如第 5-8 节 = `14:30–18:15`，第 1-2 节 = `07:40–09:20`，和教务系统完全一致。

### 关于「时间未识别」的行

网络课、课程实习、劳动教育这类**没有固定上课时间**的课程（通常挤在课表末尾一格），无法放到周课表的格子里，所以会照常列出来、但**默认不勾选**，并打上 `时间未识别` 标签。需要的话手动补上星期与节次再勾选即可。

### 识别规则

- **星期**：周一 / 星期一 / 礼拜一 / 一 / 数字 1-7 / Mon~Sun
- **节次**：`1-2节`、`第3-4节`、`第5节`、`9、10、11节`、单列 `1-2`
- **具体时间**：`08:00-09:40` 会**自动换算成第 1-2 节**（时长也一并算对）；不属于任何节次的时间（如 `12:30-13:30`）记为「自定义时间」，在课表上带「自定义」标记
- **周次**：`1-16`、`1-16单`、`2-16双`、`1-16周(单)`、`1,3,5`、`1-5,7-10,12-17`、`单周`、留空 = 每周
- **时间与时长**：课程时间由「作息时间表 + 起始节次 + 连上几节」实时换算，改作息表全站同步刷新

## 数据

- 全部数据保存在本机浏览器的 `localStorage`，不上传任何服务器。
- 「导出 JSON」可备份 / 换设备迁移；「恢复备份（JSON）」可恢复整份数据（含作息与学期设置）。
- 深链参数：`?demo=1` 预览示例课表（不写入本地数据）、`?view=grid|list|settings` 直达视图、`?week=5` 指定周次、`?day=3` 指定星期、`?mode=day|week` 指定课表模式、`?term=2026-09-02` 指定开学第一周的周一。
- 手机上访问：把 `http://<电脑局域网IP>:5188/` 在手机浏览器打开即可（同一 WiFi 下）。默认只监听 `127.0.0.1`，需要手机访问时用 `node server.js 5188 lan` 启动。

## 目录结构

```
index.html                 主程序（单文件：界面 + 解析器 + 数据，全部内联）
server.js                  本地静态服务器（零依赖）
manifest.webmanifest       添加到主屏幕用的 manifest
icon-192/512(-maskable)    应用图标（由 make-icon.js 生成）
启动.bat                    双击启动并打开浏览器
启动-手机访问.bat             局域网模式启动，供手机访问
test-parse.js              解析测试（65 项）
test-render.js             渲染 / 交互测试（87 项）
make-icon.js               重新生成图标
```

## 测试

```bash
node test-parse.js     # 65 项：时间换算 / 周次 / 表格 / 自由文本 / JSON / 矩阵 / 真实 .xls / .xlsx / GBK
node test-render.js    # 113 项：四个视图渲染 + 交互回归 + 全动作遍历 + Excel 导入全链路 + 手机端 + 学期时间校准
```

两个脚本都用 Node 直接跑，不需要浏览器、不需要任何依赖（仓库里也没有 npm 依赖）。

涉及真实 `.xls` 的那两组测试需要一个真实课表文件作样本。**为了保护隐私，这个文件默认不放在仓库目录里**（避免拖拽上传时误传到公开仓库），脚本会依次找：

1. 环境变量 `XLS_FIXTURE` 指定的路径
2. `./sample.xls`
3. `../sample-课表.xls`
4. `../sample.xls`

都没有就自动跳过这两组，其余测试照常运行（CI 上就是这种情况）。要指定自己的文件：

```bash
XLS_FIXTURE=/path/to/你的课表.xls node test-parse.js
```

CI 配置见 `.github/workflows/test.yml`。
